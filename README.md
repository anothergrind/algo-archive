# algo-archive

solving algorithm problems in various programming languages (python for now, maybe c++ and java later)

every problem gets its own folder with a `README.md` for the question and a `code.py`
for the solution.

| folder | what's in it |
| --- | --- |
| [`neetcode150/`](neetcode150/) | the neetcode 150 roadmap |
| [`leetcode/`](leetcode/) | problems from The LeetCode Beginner's Guide |
| [`synapse/`](synapse/) | synapse problems — themed takes on classic questions |
